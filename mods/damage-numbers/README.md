# Damage Numbers

- **Author:** PurplefinNeptuna
- **Download:** [GameBanana](https://gamebanana.com/mods/725408)
- **Requires [Forge](../forge/README.md):** Yes (1.4.1)
- **Mod license:** see the mod's GameBanana page
- **Status:** 🟢 Full compatibility

![Preview](preview.jpg)

## Description

Adds damage number popups, in a Wilds-style or Rise-style look.

## Install

1. Download the mod from the link above.
2. Create `mods/damage-numbers/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` folder into `mods/damage-numbers/`.

## Known issues

Not compatible with FF14-style Damage Text; install only one of the two.
