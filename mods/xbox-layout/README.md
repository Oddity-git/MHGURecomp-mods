# Xbox Controller Layout

- **Author:** ishiki
- **Download:** [GameBanana](https://gamebanana.com/mods/410801)
- **Requires [Forge](../forge/README.md):** No
- **Mod license:** see the mod's GameBanana page
- **Status:** 🟢 Full compatibility

![Preview](preview.jpg)

## Description

Replaces the button prompts with Xbox controller buttons.

## Tested with

| Recomp version or commit | Tested platform |
| --- | --- |
| 0.10.7 | Linux (CachyOS) |

## Install

1. Download the mod from the link above.
2. Create `mods/xbox-layout/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` folder into `mods/xbox-layout/`.

## Known issues

Only works with the game set to English, and the author says it is not compatible with Yuzu.
