# KatLib

- **Author:** Katt404
- **Download:** [GameBanana](https://gamebanana.com/mods/732712)
- **Requires [Forge](../forge/README.md):** Yes
- **Mod license:** see the mod's GameBanana page
- **Status:** 🟢 Full compatibility

![Preview](preview.jpg)

## Description

A shared library plugin for Katt404's Forge plugins. It does nothing on its own: UIScale, MapAssist, Sprint/Weapon Trigger Split and SkipEndQuestTime need it installed.

## Install

1. Download the mod from the link above.
2. Create `mods/katlib/` in your MHGU Recomp folder.
3. Copy the mod's `exefs` and/or `romfs` folders into `mods/katlib/`, then install the plugin that needs it.
