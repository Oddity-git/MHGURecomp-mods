## Install

1. Download the mod from the link above.
2. Create `mods/monster-hp-overlay-for-mhgu-recomp/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` and/or `exefs` folders into `mods/monster-hp-overlay-for-mhgu-recomp/`.
