- **Requires [Forge](../forge/README.md):** No
- **Mod license:** see the mod's GitHub page
- **Status:** 🟢 Full compatibility

## Description

Experimental Magnet Spike weapon mod for MHGURecomp: MHGU 1.4.0, English, single-player.

## Tested with

| Recomp version | Tested platform |
| --- | --- |
| 0.18.0 | Windows |

## Install

1. Download the mod from the link above.
2. Create `mods/mhgurecomp-magnet-spike/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` and/or `exefs` folders into `mods/mhgurecomp-magnet-spike/`.
