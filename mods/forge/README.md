# Forge

- **Author:** Fexty12573
- **Download:** [GitHub](https://github.com/Fexty12573/forge)
- **Required by:** Better Inputs, Damage Numbers, FF14-style Damage Text, Key Quest Markers
- **Mod license:** see the mod's GitHub page
- **Status:** 🟢 Full compatibility

## Description

An environment for linking, runtime hooking and code patching in Monster Hunter Generations Ultimate

## Tested with

| Recomp version or commit | Game version | Tested platform |
| --- | --- | --- |
| 0.9.1.0 | 1.4.0 | Linux |

## Install

1. Download the mod from the link above.
2. Create `mods/forge/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` and/or `exefs` folders into `mods/forge/`.
