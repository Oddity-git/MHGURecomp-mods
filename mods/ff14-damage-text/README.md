# FF14-style Damage Text

- **Author:** Filianore
- **Download:** [GameBanana](https://gamebanana.com/mods/727751)
- **Mod license:** see the mod's GameBanana page
- **Status:** 🟢 Full compatibility

## Description

Shows damage as FF14-style text with move names for every weapon and distinct colours for critical and weak-point hits. Move names follow the system language (English or Chinese).

## Install

1. Download the mod from the link above.
2. Create `mods/ff14-damage-text/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` folder into `mods/ff14-damage-text/`.
