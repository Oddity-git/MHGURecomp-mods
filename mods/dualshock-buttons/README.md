# Full DualShock Buttons

- **Author:** Abbanon
- **Download:** [GameBanana](https://gamebanana.com/mods/475878)
- **Requires [Forge](../forge/README.md):** No
- **Mod license:** see the mod's GameBanana page
- **Status:** 🟢 Full compatibility

## Description

Replaces the button prompts with PlayStation (DualShock) buttons, for all languages.

## Install

1. Download the mod from the link above.
2. Create `mods/dualshock-buttons/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` folder into `mods/dualshock-buttons/`.

## Known issues

Conflicts with the "XX Quest Clear Icon" mod by ishiki, because both change the same files. The author developed it for Ryujinx and did not test Yuzu.
