## Install

1. Download the mod from the link above.
2. Create `mods/mapassist-monster-icons-on-the-map/` in your MHGU Recomp folder.
3. Copy the mod's `romfs` and/or `exefs` folders into `mods/mapassist-monster-icons-on-the-map/`.
